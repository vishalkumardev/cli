Simple, Powerful Commands

Everything you need to automate uploads and track versions straight from your shell.

1. Authenticate Interactive or Token
buildshare login

Log in via terminal prompt or set BUILDSHARE_TOKEN in CI/CD.

2. Ship a Build APK / IPA
buildshare upload ./app-release.apk

Upload builds with real-time progress and receive instant download links.

3. List Applications JSON or Table
buildshare app list

Inspect all configured apps, package IDs, and active teams.

4. CI Automation Headless Flag
buildshare upload ./app.apk --ci --json

Runs silently in GitHub Actions or GitLab with structured JSON output.

Zero Dependencies

Pure standalone compiled Go binary. Works on clean machines without Node.js, Python, or Homebrew.

Downloads to temporary files and verifies before atomic replacement. Your existing CLI is never corrupted.
