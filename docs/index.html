Simple, Powerful Commands

Ship builds and manage releases without leaving your development flow.

1. Authenticate Interactive or Token
buildshare login

Log in via browser prompt or set BUILDSHARE_TOKEN in CI/CD.

2. Ship a Build APK / IPA
buildshare upload ./app-release.apk

Upload builds with live progress bars and receive instant shareable OTA links.

3. List Applications JSON or Table
buildshare app list

Inspect all configured apps, package IDs, and team workspaces.

4. CI Automation Headless Mode
buildshare upload ./app.apk --ci --json

Runs cleanly in GitHub Actions, GitLab CI, or CircleCI with structured JSON.

Zero Dependencies

Pure standalone compiled Go binary. Works on clean machines without Node.js, Python, or Homebrew.

Atomic Safe Installs

Downloads to temporary files and verifies before atomic replacement. Your existing CLI is never broken on download errors.

CI / CD Pipeline Ready

Runs headlessly with exit codes and clean JSON output for automated GitHub Actions and GitLab CI workflows.
