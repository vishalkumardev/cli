BuildShare CLI Reference

Complete reference for installing, configuring, and using the BuildShare CLI to distribute mobile app builds from your terminal or CI/CD pipeline.

Overview

The BuildShare CLI is a compiled Go binary that lets you upload, manage, and share Android APK and iOS IPA builds directly from your terminal. It has zero runtime dependencies — no Node.js, Python, Ruby, or package manager required.

  • Single standalone binary — runs on macOS, Linux, and Windows
  • Automatic OS & architecture detection during installation
  • Headless CI mode with structured JSON output and clean exit codes
  • Token-based authentication compatible with all CI/CD platforms
  • Real-time upload progress with shareable download links

Installation

macOS & Linux

Run the one-liner installer — it detects your OS and CPU architecture automatically, downloads the correct binary from the latest GitHub Release, verifies the checksum, and places the binary in your PATH. 

curl -fsSL https://vishalkumardev.github.io/cli/install.sh | sh

Optionally install a specific version:

BUILDSHARE_VERSION=v0.1.0 curl -fsSL https://vishalkumardev.github.io/cli/install.sh | sh

Optionally specify a custom install directory:

BUILDSHARE_INSTALL_DIR=/usr/local/bin curl -fsSL https://vishalkumardev.github.io/cli/install.sh | sh

Windows (PowerShell)

irm https://vishalkumardev.github.io/cli/install.ps1 | iex

Verify Installation

buildshare --version

Quick Start

The typical workflow from login to your first upload:

Step 1 — Authenticate 

buildshare login

Step 2 — Upload a Build 

buildshare upload ./app-release.apk

The CLI will print a shareable download URL after a successful upload.

Step 3 — View Apps 

buildshare app list

Commands

buildshare login

Authenticate with BuildShare. Opens an interactive prompt for your email and password, or reads the BUILDSHARE_TOKEN environment variable for headless/CI usage. 

buildshare login
# or supply token inline
BUILDSHARE_TOKEN=<your-token> buildshare login
Flag Description
--token <token> Provide a personal access token directly instead of interactive login

buildshare logout

Revoke the stored credentials and remove the local auth token from the config file. 

buildshare logout

buildshare whoami

Display the currently authenticated user and workspace details.

buildshare whoami

buildshare upload <file>

Upload an Android APK or iOS IPA build to BuildShare. Displays real-time progress and prints a shareable download URL on success. 

buildshare upload ./app-release.apk
buildshare upload ./app.ipa --app my-app-id --notes "Sprint 42 build"
buildshare upload ./app.apk --ci --json
Flag Description
--app <id> Target a specific app by its ID or slug
--notes <text> Release notes or change description for this build
--ci Run in non-interactive CI mode (suppresses prompts and color output)
--json Output result as structured JSON instead of human-readable text
-v, --verbose Enable detailed debug logging

buildshare app

Sub-commands for managing your applications.

buildshare app list          # List all apps in your workspace
buildshare app list --json  # Output as JSON
Sub-command Description
app list List all apps in the current workspace with package IDs and metadata

buildshare build

Sub-commands for inspecting builds.

buildshare build list --app <app-id>           # Recent builds for an app
buildshare build list --app <app-id> --json   # As JSON
Sub-command Description
build list List the most recent builds for a given app

buildshare version

Print the installed version number, commit SHA, and build date.

buildshare version
buildshare --version

Global Flags

These flags are available on every command:

Flag Short Description
--json — Output results as structured JSON for scripting and automation
--ci — Non-interactive CI mode — suppresses prompts, colors, and spinners
--verbose -v Enable debug logging for detailed request/response traces
--help -h Print help information for a command
--version — Print the CLI version

Environment Variables

Environment variables override all flags and config file values, making them ideal for CI/CD secrets.

Variable Description
BUILDSHARE_TOKEN Personal access token. Set this in CI to authenticate without interactive login.
BUILDSHARE_API_URL Override the base API URL (for self-hosted or staging environments).

💡 Tip: In GitHub Actions, store your token as a secret (Settings → Secrets → Actions) and reference it as ${{ secrets.BUILDSHARE_TOKEN }}.

CI / CD Integration

GitHub Actions

name: Upload Build to BuildShare

on:
  push:
    branches: [ main ]

jobs:
  upload:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Install BuildShare CLI
        run: curl -fsSL https://vishalkumardev.github.io/cli/install.sh | sh

      - name: Build APK
        run: ./gradlew assembleRelease

      - name: Upload to BuildShare
        env:
          BUILDSHARE_TOKEN: ${{ secrets.BUILDSHARE_TOKEN }}
        run: buildshare upload ./app/build/outputs/apk/release/app-release.apk --ci --json

GitLab CI

upload_build:
  stage: deploy
  script:
    - curl -fsSL https://vishalkumardev.github.io/cli/install.sh | sh
    - buildshare upload ./app-release.apk --ci --json
  variables:
    BUILDSHARE_TOKEN: $BUILDSHARE_TOKEN

Bitbucket Pipelines

pipelines:
  default:
    - step:
        name: Upload to BuildShare
        script:
          - curl -fsSL https://vishalkumardev.github.io/cli/install.sh | sh
          - buildshare upload ./app-release.apk --ci --json
        environment:
          BUILDSHARE_TOKEN: $BUILDSHARE_TOKEN

Exit Codes

The CLI uses standard exit codes so CI/CD pipelines can automatically detect failures:

Code Meaning
0 Success
1 General error (authentication failure, network error, invalid file)
2 Misuse — invalid command or missing required argument

Manual Installation

If you prefer manual installation or have restricted network access, download the pre-built binary directly from the GitHub Releases page.

Available Binaries

Platform Filename
macOS Apple Silicon buildshare_<version>_darwin_arm64.tar.gz
macOS Intel buildshare_<version>_darwin_amd64.tar.gz
Linux x86_64 buildshare_<version>_linux_amd64.tar.gz
Linux ARM64 buildshare_<version>_linux_arm64.tar.gz
Windows x64 buildshare_<version>_windows_amd64.zip

macOS / Linux Steps

tar -xzf buildshare_*.tar.gz
sudo mv buildshare /usr/local/bin/
sudo chmod +x /usr/local/bin/buildshare
buildshare --version

Windows Steps

Extract the .zip archive and move buildshare.exe to a directory in your PATH (e.g. %LOCALAPPDATA%\Programs\buildshare\bin). Then open a new terminal and run: 

buildshare --version

⚠️ SHA-256 Checksums: Every release includes a checksums.txt file you can use to verify binary integrity before installation: shasum -a 256 -c checksums.txt
